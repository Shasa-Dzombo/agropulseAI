## 🔬 FIRMWARE SPECIFICATIONS

### Hardware Requirements
- **Microcontroller**: ESP32-CAM (Dual-core, WiFi, Camera)
- **Sensors Required**:
  1. DHT22: Temperature & Humidity
  2. MH-Z19B: CO2 concentration (0-5000 ppm)
  3. LI-190R or equivalent: PAR light sensor
  4. pH sensor: 0-14 pH range
  5. EC sensor: 0-10 mS/cm range
  6. DS18B20: Water temperature (OneWire)
  7. Capacitive moisture sensor: Substrate moisture

### Camera Configuration
- **Resolution**: 800x600 (SVGA) or 640x480 (VGA)
- **Frame Rate**: 1 frame per 5 minutes
- **LED Compensation**: Auto white balance, exposure control
- **Analysis**: On-chip color segmentation for health assessment

### Sensor Reading Intervals
- **Environmental Sensors**: Every 60 seconds
- **Camera Capture**: Every 5 minutes
- **Data Upload**: Every 10 minutes

### Data Transmission
- **Protocol**: HTTPS REST API
- **Format**: JSON with gzip compression
- **Fallback**: Local SD card logging when offline
- **Security**: Bearer token authentication

## 📊 CROP PARAMETER DATABASE

Each crop includes precise parameters:
- **pH Range**: Optimal hydroponic/soil pH
- **EC Range**: Electrical conductivity (nutrient concentration)
- **Temperature**: Day/night optimal ranges
- **Humidity**: Relative humidity optimal range
- **CO2**: Optimal CO2 enrichment levels
- **PAR Light**: Photosynthetically active radiation
- **Water Sensitivity**: Crop-specific stress threshold (0-1)

### Real-Time Analysis
The firmware continuously:

1. Reads all sensors every minute
2. Compares values to crop-specific optimal ranges
3. Calculates VPD (Vapor Pressure Deficit)
4. Performs vision analysis on plant health
5. Detects diseases and pests
6. Generates alerts for out-of-range conditions
7. Uploads data to cloud platform

### 1. **Crop-Specific Optimization**
Each of the 25 crops has unique optimal ranges programmed into firmware. The system automatically adjusts monitoring thresholds based on selected crop.

ESP32 performs real-time image analysis:
- Health index calculation
- Stress indicator detection
- Disease/pest identification
- Leaf area index estimation

### 5. **Multi-Parameter Correlation**
System correlates environmental data with vision analysis to provide comprehensive plant health assessment.

### 6. **Automatic Alerting**
Generates alerts when parameters fall outside crop-specific optimal ranges:
- ⚠️ Temperature too high/low
- ⚠️ Humidity outside range
- ⚠️ CO2 insufficient
- ⚠️ PAR light too low
- ⚠️ pH drift
